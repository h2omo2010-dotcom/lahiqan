# لاحقاً

أداة عائمة لويندوز: تحويل PDF / وورد / إكسل / الصور / الفيديو، محرر PDF، ومدير تحميلات يكمل بعد انقطاع الإنترنت (ملفات مباشرة ويوتيوب).

## التحميل

حمّل **Lahiqan-Setup.exe** من [آخر إصدار](../../releases/latest) وشغّله — يثبّت البرنامج كاملاً ويضع اختصاراً على سطح المكتب.

- يعمل على ويندوز 10 و 11 (64 بت).
- التحديثات تنزل تلقائياً: البرنامج يفحص آخر إصدار ويثبّته عند التشغيل التالي.
- تحويلات وورد وإكسل تحتاج Microsoft Office مثبّتاً على الجهاز.
- ويندوز قد يعرض تحذير «ناشر غير معروف» لأن الملف غير موقَّع: اضغط «مزيد من المعلومات» ثم «تشغيل على أي حال».
